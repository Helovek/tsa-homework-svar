# Данные

Исходные и обработанные данные не публикуются. В проекте использованы квартальные ряды по России: ВВП, ИПЦ, заработная плата, M2, ключевая ставка, цены промежуточных материалов, просроченная задолженность и сырьевые цены.

Источники: Росстат/ЕМИСС, Банк России и ИЭП. Для запуска скриптов необходимо самостоятельно подготовить `data/processed/svar_dataset.csv`.
